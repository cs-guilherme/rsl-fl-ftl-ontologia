# Formulário de extração

Campos preenchidos para cada estudo incluído (arquivo `extracao_R1.csv`), conforme a seção 11 do protocolo.

| Campo | Descrição |
|---|---|
| ID | Identificador do registro na triagem (R1-NNNN) |
| Título | Título do estudo |
| Ano | Ano de publicação |
| Eixos | Eixos da busca em que o estudo apareceu |
| Relevância final | Núcleo (sustenta o estado da arte e a lacuna), Apoio (base para o método) ou Periférico (contexto) |
| Por que importa para a proposta | Relação do estudo com o PICO e uso previsto no artigo |
| Problema | Problema tratado pelo estudo |
| Domínio e dados | Domínio de aplicação e tipo de dados (tabulares, texto, imagem), número de clientes ou domínios |
| Abordagem | Abordagem de FL ou FTL (algoritmo, agregação, uso de protótipos) |
| Uso de ontologia | Ontologia usada, papel no pipeline e forma de avaliação |
| Variação dos dados | Variação ou perturbação estudada (tipo, intensidade, como foi controlada) |
| Modelos e métricas | Modelos e métricas de avaliação |
| Repetições e estatística | Número de repetições e testes estatísticos |
| Resultados | Principais resultados |
| Limitações | Limitações declaradas ou observadas |
| Relação com a proposta | Semelhanças e diferenças em relação ao artigo |
| Texto lido | Fonte do texto completo consultado |
| Observação da leitura completa | Observações da leitura do texto completo |
